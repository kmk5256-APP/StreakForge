# StreakForge 🔥

A modern, beautiful habit tracker built with SwiftUI for iOS.

## Features
- Create and track daily/weekly habits
- Visual streaks and progress rings
- Calendar history view
- Smooth animations and haptic feedback
- Dark mode support
- Local persistence with SwiftData
- Clean, gradient-rich design

## Getting Started
1. Clone the repo
2. Open in Xcode 16+
3. Create a new iOS App project (SwiftUI, SwiftData) named StreakForge
4. Replace the generated files with the ones in this repo (or drag them in)
5. Build & Run on iPhone simulator or device
